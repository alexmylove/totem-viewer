ПРОСМОТРЩИК TOTEM GLB

Модель, библиотека и просмотрщик уже в комплекте. Анимация повторяется автоматически. Мышь плавно поворачивает модель. Окружение прозрачное. Кнопки: пауза и возврат ракурса. На телефоне работает автоматическая анимация, без перехвата прокрутки.

1. Распакуйте архив.
2. На GitHub создайте публичный репозиторий totem-viewer.
3. Через Add file → Upload files загрузите СОДЕРЖИМОЕ папки glb-viewer. index.html должен оказаться в корне репозитория; папку vendor загружайте вместе с остальными файлами.
4. Откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Дождитесь публикации и откройте https://ВАШ-ЛОГИН.github.io/totem-viewer/ — это готовый просмотрщик с кнопками.
6. Для Тильды откройте TILDA.html текстовым редактором, замените YOUR-LOGIN своим логином, скопируйте весь код в блок T123 и опубликуйте страницу. Старый код анимации удалите.

?controls=0 скрывает кнопки в виджете. Удалите этот параметр из ссылки iframe, если кнопки нужны. Высоту вставки задаёт aspect-ratio:1.45.

ЛОКАЛЬНЫЙ ПРОСМОТР
Прямое открытие index.html двойным щелчком не подходит для загрузки GLB и модулей. Если установлен Python, откройте терминал в папке glb-viewer, выполните python -m http.server 8000 и откройте http://localhost:8000. Устанавливать Python ради публикации не нужно — можно сразу использовать GitHub Pages.

Для замены модели сохраните другой файл под именем totem-layers.glb. Ракурс и масштаб в viewer.js настроены именно для модели TOTEM.

Если модель не появилась: убедитесь, что загружены папка vendor, viewer.js и totem-layers.glb; адрес начинается с https:// и указывает на GitHub Pages. Нужен браузер с WebGL. При включённой системной настройке уменьшения движения модель отображается статично. За пределами экрана и на скрытой вкладке движение приостанавливается.
